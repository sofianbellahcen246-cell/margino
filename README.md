# Margino

Margino è un prototipo di calcolatore di profitto per chi vende online.

## Avvio
Il progetto è un sito statico: apri `index.html` nel browser oppure pubblicalo con GitHub Pages.

## Stato attuale
- Calcolo automatico del profitto, dei costi totali, del margine e del profitto su 10 vendite.
- Prezzi PRO mostrati come proposta: 3,99 €/mese oppure 29,99 €/anno.
- Pagamenti, account, abbonamenti e funzioni PRO non sono ancora attivi.
- Il sito non raccoglie né invia dati a un server.

## Pubblicazione con GitHub Pages
Nel repository apri **Settings → Pages**. In **Build and deployment**, scegli **Deploy from a branch**, seleziona il branch **main** e la cartella **/(root)**, poi salva. Attendi la pubblicazione e usa l'indirizzo mostrato nella stessa pagina.

Prima di vendere abbonamenti servono un backend per account e autorizzazioni, pagamenti con webhook verificati, privacy policy e termini. Non inserire mai chiavi segrete di pagamento nel codice pubblico.
